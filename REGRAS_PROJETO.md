# Regras do projeto

Estas regras orientam toda alteração futura no projeto. O usuário pode atualizá-las conforme as decisões evoluírem.

1. **Imports no início:** imports de bibliotecas devem ficar em uma única célula no início do projeto. Se houver uma célula de instalação de dependências, a célula de imports deve ser a segunda célula.
2. **Arquivo único executável:** o programa deve rodar a partir de um único arquivo, adequado ao Google Colab. Não criar dependências de outros notebooks ou de arquivos auxiliares de código para a execução principal.
3. **Livros no Google Drive:** o caminho dos livros será fornecido/configurado pelo usuário no Google Drive, e o programa deve buscar os PDFs a partir desse local.
4. **Escopo de conteúdo:** o projeto é estritamente focado em Dungeons & Dragons 5ª edição e 5.5 (2024). Não ampliar o escopo para outros sistemas ou edições sem uma mudança explícita desta regra pelo usuário.
5. **Busca por página:** o algoritmo deve localizar e recuperar informações do livro por página, preservando a identificação da página nas evidências e nas citações. Não usar trechos (chunks) como unidade principal de busca.
